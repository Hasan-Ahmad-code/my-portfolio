Adaptive Context Reliance Control Final-year project

A system that dynamically controls how much a RAG pipeline relies on retrieved context under noisy retrieval conditions, to improve response accuracy. Built on a small dataset with all-MiniLM-L6-v2 embeddings; ten structured experiments across chunk size, embedding models, distance metrics, and noise injection — the key finding being that relevance is a continuous spectrum, and fixed thresholds are fragile.

Finalist, P@SHA ICT Awards 2026, Tertiary Students category.

Sustainability Report Extraction Pipeline

A RAG pipeline with page-aware PDF ingestion, overlapping chunking, and FAISS dense retrieval (all-MiniLM-L6-v2 embeddings, cosine similarity) to index long, unstructured corporate ESG reports. Uses a taxonomy-guided extraction schema with few-shot chain-of-thought prompting to constrain LLM outputs to structured, validated JSON. An explainability layer produces per-claim source citations and retrieval-confidence scores to mitigate hallucination risk, with rate-limit-aware retry logic and a Streamlit inference demo.

AI-Based Exam Paper Generator using RAG

A RAG pipeline that converts a PDF into a formatted exam paper with an answer key, using inference-time generation via Groq's LLaMA-3.1-8b-instant and FAISS dense retrieval (all-MiniLM-L6-v2). A multi-type question generator produces MCQs, True/False, short answer, fill-in-the-blank, and descriptive questions across three Bloom's Taxonomy difficulty levels, with output validation and marks enforcement. Benchmarked against a TF-IDF lexical baseline using ROUGE-L and Flesch-Kincaid readability metrics — RAG-generated questions were more analytical and less directly extractive of source text.

Cheating Detection in Exam Halls

A vision-based deep learning system for real-time cheating detection in exam halls, using a CNN-LSTM architecture — ResNet-18 for spatial feature extraction and LSTM for temporal behavior modeling. Curated a self-collected dataset of 7,200 frames across 11 behavior categories from multiple camera angles, achieving 89.92% validation accuracy, 97.48% recall, and a 90.62% F1 score at the optimal checkpoint.
