Abstract

I study how large language models manage memory and adapt at inference time — when a model should trust retrieved context over its own parametric knowledge, and how it can adjust its behaviour without retraining. My current work is a survey of dynamic memory and test-time adaptation, alongside applied research in retrieval-augmented systems.

Keywords — large language models, retrieval-augmented generation, test-time adaptation, dynamic memory, natural language processing

Research focus

My current survey covers 30+ papers across six themes in dynamic memory and LLM adaptation.

Dynamic memory

How LLMs store and retrieve information within and across contexts, including KV-cache and external memory.

Test-time adaptation

Techniques that let models adapt to new distributions at inference time — without retraining.

Adaptive context

Deciding when to trust retrieved context over parametric knowledge — a key challenge in RAG and beyond.
